# Система мониторинга серверов (Лабораторная работа №7)

## Описание проекта
Проект представляет собой веб-приложение для мониторинга нагрузки на серверы. 
В рамках лабораторной работы №7 в проект была добавлена поддержка технологии WebSocket (библиотека Socket.IO) для отображения уведомлений о критических событиях в реальном времени, а также реализовано сохранение истории этих событий в базу данных MongoDB.

## Используемые технологии
* **Фронтенд:** React (Vite), Axios, Socket.IO-client.
* **Бэкенд:** Node.js, Express, Socket.IO, Sequelize (PostgreSQL), Mongoose (MongoDB).
* **Базы данных:** PostgreSQL (хранение основных метрик) и MongoDB (хранение истории алертов).

## Инструкция по запуску

Для запуска проекта вам потребуется два терминала (один для бэкенда, другой для фронтенда).

### 1. Запуск бэкенда (серверная часть)
1. Откройте терминал и перейдите в папку с бэкендом:
   ```bash
   cd server-monitoring-api
2. Установите зависимости:
npm install
3. Создайте файл .env в корне папки server-monitoring-api и заполните его.
Для подключения к облачной базе данных Neon вам нужна строка подключения (Connection String), которую вы можете взять в панели управления Neon (кнопка "Connect"):

PORT=3000
DATABASE_URL=postgresql://[user]:[password]@[neon_hostname]/[dbname]?sslmode=require
MONGO_URI=mongodb://localhost:27017/server_monitoring
JWT_SECRET=ваш_секретный_ключ
Примечание: если вы используете облачную MongoDB Atlas, замените MONGO_URI на вашу строку подключения от Atlas.

4.Выполните миграции для создания таблиц в облачной базе данных:
npx sequelize-cli db:migrate
